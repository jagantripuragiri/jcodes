FAQ

Common questions

Is J Code's free and open source?

Yes. J Code's is licensed under the MIT License and built on the open-source VS Code and Void projects. Source and releases are on GitHub.

Which AI models can I use?

J Code's supports Anthropic Claude, Google Gemini, OpenAI (GPT-4o, o1, o3), DeepSeek, Groq, and local models via Ollama. Configure providers and API keys from the Settings pane (Cmd/Ctrl + ,).

macOS says the app "is damaged" or can't be checked — what do I do?

This is macOS Gatekeeper. Open Terminal and run xattr -cr "/Applications/J code's.app", or right-click the app in Finder and choose Open.

Will my existing VS Code extensions and settings work?

Yes. J Code's is built on VS Code 1.99, so keybindings, settings, syntax highlighting, and extensions carry over.
